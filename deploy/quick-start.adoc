= Avvio rapido dei tool ONTAP per VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configura ONTAP tools for VMware vSphere con questa guida rapida.

Completa prima queste attività principali per rendere operativi gli ONTAP tools per la configurazione e il provisioning iniziali. Successivamente, completa le attività facoltative in base al tuo ambiente e ai requisiti di protezione.

Inizialmente, distribuisci ONTAP tools for VMware vSphere come una configurazione a nodo singolo extra-small (XS) che fornisce servizi principali per i datastore NFS e VMFS. Se hai bisogno di container aggiuntivi per servizio, maggiore resilienza o datastore vVols e alta disponibilità (HA), completa prima questo flusso di lavoro e poi continua con l'espansione. Per ulteriori informazioni, consulta il link:../deploy/ha-workflow.html["Workflow di implementazione HA"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"] Pianificare la distribuzione
[role="quick-margin-para"]
Conferma che il tuo ambiente sia pronto per una distribuzione supportata. Verifica che le versioni di vSphere, ONTAP e dell'host ESXi siano compatibili con la versione degli ONTAP tools. Alloca CPU, memoria e spazio su disco sufficienti. In base alle tue regole di sicurezza, potresti dover configurare firewall o altri controlli di sicurezza per consentire il traffico di rete.

[role="quick-margin-para"]
Assicurati che vCenter Server sia installato e accessibile.

[role="quick-margin-list"]
* https://imt.netapp.com/matrix/#welcome["Tool di matrice di interoperabilità"]
* link:../deploy/prerequisites.html["Strumenti ONTAP per requisiti e limiti di configurazione VMware vSphere"]
* link:../deploy/pre-deploy-checks.html["Prima di iniziare"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"] Implementa i tool ONTAP per VMware vSphere
[role="quick-margin-para"]
Distribuisci l'appliance ONTAP tools per stabilire i servizi di base per i datastore NFS e VMFS.

[role="quick-margin-para"]
Se prevedi di espandere la tua distribuzione per i datastore vVols e HA, completa prima questo flusso di lavoro. In ONTAP tools for VMware vSphere 10.6, l'aggiunta a caldo della CPU e il memory hot-plug sono abilitati per impostazione predefinita.

[role="quick-margin-para"]
Durante la distribuzione, esamina attentamente i campi di *Customize template*, in particolare host name, utilizzo dell'indirizzo IP di ONTAP tools e requisiti DNS.

[role="quick-margin-list"]
* link:../deploy/ontap-tools-deployment.html["Implementa i tool ONTAP per VMware vSphere"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]Registrati e installa il plug-in client vCenter
[role="quick-margin-para"]
Aggiungi un'istanza del server vCenter per registrare il plug-in client vCenter e applicare i privilegi e i ruoli necessari. Quando aggiungi un'istanza del server vCenter, ONTAP tools registra il plug-in remoto, applica privilegi personalizzati per il plug-in e le API, crea ruoli personalizzati e aggiunge un collegamento al plug-in nell'interfaccia utente vSphere.

[role="quick-margin-list"]
* link:../configure/add-vcenter.html["Aggiungere istanze di vCenter Server agli strumenti ONTAP"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]Configura i backend di storage
[role="quick-margin-para"]
Connetti le risorse di storage ONTAP così che ONTAP tools possa eseguire il provisioning e gestire i datastore. Aggiungi un backend di storage a un cluster ONTAP. Negli ambienti multitenant in cui un vCenter Server è associato a un tenant SVM, usa ONTAP tools Manager per aggiungere il cluster. Poi associa il backend di storage al vCenter Server per creare una mappatura globale per quella istanza di vCenter.

[role="quick-margin-para"]
Aggiungi backend di storage locali con credenziali del cluster o SVM utilizzando l'interfaccia degli ONTAP tools. Questi backend di storage sono limitati a un singolo vCenter. Quando utilizzi le credenziali del cluster localmente, le SVM associate vengono mappate automaticamente al vCenter per la gestione di vVol o VMFS. Per la gestione di VMFS, incluso SRA, ONTAP tools supporta le credenziali SVM senza richiedere un cluster globale.

[role="quick-margin-list"]
* link:../configure/add-storage-backend.html["Aggiungere un backend di storage"]
* link:../configure/associate-storage-backend.html["Associare il backend dello storage a un'istanza di vCenter Server"]

== Attività successive facoltative

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]Configura i ruoli e i privilegi utente ONTAP
[role="quick-margin-para"]
Configura ruoli ONTAP personalizzati per l'accesso con privilegi minimi invece di usare l'account admin predefinito.

[role="quick-margin-list"]
* link:../configure/configure-user-role-and-privileges.html["Configurare i ruoli e i privilegi degli utenti ONTAP"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]Aggiorna i certificati per più istanze di vCenter Server
[role="quick-margin-para"]
Aggiorna i certificati per utilizzare una comunicazione affidabile basata su certificati tra più istanze del server vCenter.

[role="quick-margin-list"]
* link:../manage/certificate-manage.html["Gestire i certificati"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]Configura la protezione SRA
[role="quick-margin-para"]
Abilita la funzionalità SRA per configurare la protezione di ripristino di emergenza per i datastore NFS e VMFS.

[role="quick-margin-list"]
* link:../manage/enable-services.html["Abilita i tool ONTAP per i servizi VMware vSphere"]
* link:../protect/configure-on-srm-appliance.html["Configurare SRA sull'appliance VMware Live Site Recovery"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"] Abilita la protezione di sincronizzazione attiva SnapMirror
[role="quick-margin-para"]
Configura la protezione del cluster host con SnapMirror active sync per proteggere i datastore VMFS. Nei sistemi ONTAP, esegui il peering dei cluster e degli SVM necessari, quindi configura la protezione negli ONTAP tools. Questa opzione si applica solo ai datastore VMFS.

[role="quick-margin-list"]
* link:../protect/config-proximity.html["Configura il cluster per la protezione del datastore con ONTAP tools"]
* link:../protect/protect-multiple-ds.html["Proteggi i datastore in un cluster"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinque"]Configura il backup e il ripristino per la tua distribuzione di ONTAP tools
[role="quick-margin-para"]
Configura backup e ripristino per proteggere la configurazione di ONTAP tools e recuperare rapidamente dai guasti.

[role="quick-margin-para"]
Il backup è abilitato di default in ONTAP tools for VMware vSphere 10.6 e viene eseguito ogni 10 minuti.

[role="quick-margin-list"]
* link:../manage/backup-settings.html["Modifica le impostazioni di backup"]
* link:../manage/recover-backup.html["Ripristina la configurazione degli strumenti ONTAP"]
