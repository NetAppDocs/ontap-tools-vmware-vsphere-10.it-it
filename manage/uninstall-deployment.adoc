= Disinstalla la tua distribuzione di ONTAP tools for VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La disinstallazione di ONTAP tools per VMware vSphere elimina i dati nell'appliance, quindi completa questi passaggi per arrestare correttamente l'implementazione ed evitare perdite di dati impreviste.

.Fasi
. Rimuovere o spostare tutte le macchine virtuali dai tool ONTAP per datastore gestiti da VMware vSphere.
+
** Per rimuovere le macchine virtuali, fare riferimento alla https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-virtual-machine-administration-guide-8-0/managing-virtual-machinesvsphere-vm-admin/adding-and-removing-virtual-machinesvsphere-vm-admin.html#GUID-376174FE-F936-4BE4-B8C2-48EED42F110B-en["Rimuovere e registrare nuovamente le macchine virtuali e i modelli VM"]
** Per spostarli in un datastore non gestito, consulta  https://techdocs.broadcom.com/["Documentazione Tecnica Broadcom"] per la migrazione delle macchine virtuali con Storage vMotion


. link:../manage/delete-ds.html["Elimina datastore"] Creato su tool ONTAP per VMware vSphere.
. Se hai abilitato il VASA Provider, seleziona *Impostazioni* > *Impostazioni VASA Provider* > *Annulla registrazione* in ONTAP tools per annullare la registrazione del VASA Provider da tutte le istanze del server vCenter.
. Rimuovere l'adattatore SRA da VMware Live Site Recovery:
+
.. Accedere come amministratore all'interfaccia di gestione dell'appliance VMware Live Site Recovery utilizzando la porta 5480.
.. Selezionare *schede di replica archiviazione*.
.. Selezionare la scheda SRA appropriata, quindi scegliere *Elimina* dal menu a discesa.
.. Verificare di conoscere i risultati dell'eliminazione della scheda e selezionare *Elimina*.


. Rimuovi le istanze di vCenter Server integrate in ONTAP tools for VMware vSphere. Fai riferimento a link:../manage/manage-vcenter.html["Gestire le istanze di vCenter Server"].
+
Quando rimuovi un'istanza di vCenter Server, ONTAP tools può guidarti nella procedura di pulizia necessaria. Se richiesto nella finestra di dialogo *Remove vCenter*, seleziona *Remove all storage artifacts from this vCenter Server* e *I understand that the associated datastores will no longer be managed by ONTAP tools*, quindi seleziona *Force delete*.

+
Prima di utilizzare *Eliminazione forzata*, assicurati che tutti i datastore vVols siano rimossi o migrati, che tutti i datastore protetti siano non protetti e che non siano in esecuzione processi di rilevamento.

+
Se il server vCenter non è raggiungibile durante l'eliminazione, ONTAP tools rimuove solo il record del server vCenter. Devi annullare manualmente la registrazione del plug-in da VMware vCenter Server.

. Spegnere gli strumenti ONTAP per le VM VMware vSphere da vCenter Server ed eliminare le VM.
