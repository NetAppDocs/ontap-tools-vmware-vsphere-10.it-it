= Modificare le impostazioni degli host ESXi utilizzando gli strumenti ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Usa la dashboard di ONTAP tools in VMware vSphere per identificare i problemi di configurazione, rivedere le impostazioni consigliate da NetApp per gli host ESXi selezionati e applicarle.

.Prima di iniziare
Il portlet dei sistemi host ESXi visualizza i problemi con le impostazioni dell'host ESXi.  Seleziona un problema per visualizzare il nome host o l'indirizzo IP.

.Fasi
. Accedi al vSphere Client.
. Nella pagina Collegamenti rapidi, seleziona *NetApp ONTAP tools* nella sezione Plug-in.
. Vai al portlet *Conformità host ESXi* nella dashboard Panoramica del plug-in ONTAP tools for VMware vSphere.
. Seleziona il link *Applica impostazioni consigliate*.
. Nella finestra *Applica impostazioni host consigliate*, seleziona gli host per cui vuoi applicare le impostazioni host consigliate NetApp, quindi seleziona *Avanti*.
+

NOTE: È possibile espandere l'host ESXi per visualizzare i valori correnti.

. Nella pagina Impostazioni, seleziona i valori consigliati secondo necessità.
. Nel riquadro di riepilogo, verifica i valori e seleziona *Fine*. Puoi monitorare l'avanzamento nel pannello Attività recenti.
