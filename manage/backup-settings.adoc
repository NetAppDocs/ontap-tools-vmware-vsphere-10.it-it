= Modifica le impostazioni di backup di ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partire da ONTAP tools for VMware vSphere 10.5, i backup sono abilitati per impostazione predefinita e vengono eseguiti ogni 10 minuti. Puoi disabilitare i backup o modificarne la frequenza.

Non disabilitare il backup perché impedisce a ONTAP tools di mantenere un basso recovery point objective (RPO). La disabilitazione del backup non elimina i file di backup esistenti. Puoi cambiare la frequenza del backup impostandola su un valore tra 10 e 60 minuti.

.Fasi
. Avviare Gestione strumenti ONTAP da un browser Web: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Effettua l'accesso con i tool ONTAP per le credenziali di amministratore di VMware vSphere fornite durante l'implementazione.
. Selezionare l'opzione *Impostazioni* > *Backup* > *Modifica*.
. Nella finestra di modifica, disabilita il backup o modifica la frequenza del backup.
