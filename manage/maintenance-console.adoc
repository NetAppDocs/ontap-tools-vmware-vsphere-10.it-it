= Console di manutenzione degli strumenti ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La console di manutenzione per gli ONTAP tools for VMware vSphere consente di gestire le impostazioni di applicazioni, sistema e rete.  È possibile aggiornare le password di amministratore e manutenzione, generare bundle di supporto, configurare i livelli di registro, gestire le impostazioni TLS e abilitare la diagnostica remota.

Dopo aver distribuito ONTAP tools for VMware vSphere, se la console di manutenzione non è accessibile, installa VMware Tools dal vCenter Server. Accedi usando il `maint` nome utente e la password impostati durante la distribuzione. Usa *nano* per modificare i file nella console di manutenzione o nella console di accesso root.


NOTE: Imposta una password per l' `diag`utente quando abiliti la diagnostica remota.

Usa la scheda *Summary* degli ONTAP tools for VMware vSphere distribuiti per accedere alla console di manutenzione. Seleziona image:../media/launch-maintenance-console.gif["Pulsante Play (Riproduci)"] per avviare la console di manutenzione.

|===


| *Menu console* | *Opzioni* 


 a| 
Configurazione dell'applicazione
 a| 
. Visualizza il riepilogo dello stato del server
. Modifica il livello LOG per i servizi degli strumenti ONTAP
. Cambia il flag di convalida del certificato




 a| 
Configurazione del sistema
 a| 
. Riavviare la macchina virtuale
. Spegni la macchina virtuale
. Genera un token per reimpostare la password dell'interfaccia utente del manager
. Modificare il fuso orario
. Aumentare la dimensione del disco jail (/jail)
. Eseguire l'upgrade
. Installare VMware Tools
. Aggiorna le credenziali di vCenter
. Aggiorna i certificati dei servizi ONTAP tools




 a| 
Configurazione di rete
 a| 
. Visualizzare le impostazioni dell'indirizzo IP
. Visualizzare le impostazioni di ricerca dei nomi di dominio
. Modificare le impostazioni di ricerca dei nomi di dominio
. Visualizza percorsi statici
. Modificare i percorsi statici
. Eseguire il commit delle modifiche
. Eseguire il ping di un host
. Ripristinare le impostazioni predefinite




 a| 
Supporto e diagnostica
 a| 
. Accedere alla shell di diagnostica
. Abilitare l'accesso remoto alla diagnostica
. Fornisci le credenziali vCenter per il backup
. Esegui backup


|===
