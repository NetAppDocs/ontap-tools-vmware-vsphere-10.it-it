= Reimposta la password della console di manutenzione di ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Durante il riavvio del sistema operativo guest, il menu GRUB visualizza un'opzione per reimpostare la password dell'utente della console di manutenzione. Usa questa opzione per aggiornare la password sulla VM. Dopo che hai reimpostato la password, la VM si riavvia. In una distribuzione HA, il sistema aggiorna automaticamente la password sulle altre due VM dopo il riavvio.


NOTE: Per una distribuzione HA di ONTAP tools for VMware vSphere, cambia la password dell'utente della console di manutenzione sul nodo di gestione di ONTAP tools (node1).

.Fasi
. Accedere a vCenter Server
. Fai clic con il pulsante destro del mouse sulla macchina virtuale e seleziona *Alimentazione* > *Riavvia sistema operativo guest*. Durante il riavvio del sistema, viene visualizzata la seguente schermata: image:../media/maint-console-password.png["Reimpostare la password dell'utente di manutenzione"]
+
Hai cinque secondi per scegliere un'opzione. Premi un tasto qualsiasi per interrompere il conto alla rovescia e mettere in pausa il menu GRUB.

. Selezionare l'opzione *Reimposta password utente manutenzione*. Si apre la console di manutenzione.
. Nella console, inserisci e conferma la nuova password.  Hai tre tentativi.  Il sistema si riavvia dopo aver inserito correttamente la nuova password.
. Premere *Invio* per continuare.  Il sistema aggiorna la password sulla VM.



NOTE: Lo stesso menu GRUB appare quando accendi la macchina virtuale. Usa l'opzione di reimpostazione della password solo con *Restart Guest OS*.
