= Pulisci le configurazioni VASA negli ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Segui questi passaggi per completare la pulizia di VASA in ONTAP tools.


NOTE: Rimuovi tutti i datastore vVols prima di avviare la pulizia di VASA.

.Fasi
. Apri  `\https://OTV_IP:8143/Register.html` per annullare la registrazione del plug-in.
. Verificare che il plug-in non sia più disponibile su vCenter Server.
. Spegni la macchina virtuale (VM) ONTAP tools for VMware vSphere.
. Elimina i tool ONTAP per VMware vSphere VM.
