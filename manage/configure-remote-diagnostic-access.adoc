= Configurare l'accesso diagnostico remoto per ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi abilitare l'accesso SSH per l'utente diag in ONTAP tools for VMware vSphere.

.Prima di iniziare
Abilita l'estensione VASA Provider per la tua istanza di vCenter Server.

.A proposito di questa attività
L'utilizzo di SSH per accedere all'account utente DIAG presenta le seguenti limitazioni:

* Puoi usare solo un account di accesso alla volta ogni volta che abiliti SSH.
* L'accesso SSH all'account utente diag è disabilitato in entrambi questi casi:
+
** Il tempo scade.
+
La sessione di accesso scade a mezzanotte del giorno successivo.

** Si accede nuovamente come utente di DIAG utilizzando SSH.




.Fasi
. Accedi al vCenter Server.
. Individua la macchina virtuale ONTAP tools e avvia la console web.
. Accedi utilizzando le `maint` credenziali.
. Immettere `4` per selezionare *supporto e diagnostica*.
. Entra `2` per selezionare *Abilita accesso alla diagnostica remota*.
. Inserisci `y` nella finestra di dialogo di conferma per abilitare l'accesso diagnostico remoto.
. Inserire una password per l'accesso remoto alla diagnostica.
