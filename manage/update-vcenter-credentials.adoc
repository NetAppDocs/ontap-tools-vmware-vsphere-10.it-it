= Aggiorna le credenziali del server vCenter negli ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Usa la console di manutenzione per aggiornare le credenziali dell'istanza vCenter Server.

.Prima di iniziare
Hai bisogno delle credenziali dell'utente di manutenzione.

.A proposito di questa attività
Se hai modificato le credenziali di vCenter Server dopo la distribuzione, aggiornale utilizzando questa procedura.

.Fasi
. Accedi al vCenter Server.
. Individua la macchina virtuale ONTAP tools e avvia la console web.
. Accedi utilizzando le `maint` credenziali.
. Inserire `2` per selezionare il menu Configurazione di sistema.
. Entra `8` per modificare le credenziali di vCenter.
