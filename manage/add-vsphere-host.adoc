= Aggiungere host VMware vSphere a ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Aggiungi nuovi host VMware vSphere agli ONTAP tools for VMware vSphere così puoi gestire e proteggere i datastore degli host.

.Fasi
. Aggiungi un host al tuo cluster vSphere seguendo le  https://techdocs.broadcom.com/["Documentazione Tecnica Broadcom"].
. Dopo aver aggiunto l'host, vai al menu principale di ONTAP tools e seleziona *Discover* nel pannello di panoramica, oppure attendi il completamento del rilevamento host pianificato.


.Risultato
Il nuovo host è ora rilevato e gestito da ONTAP tools for VMware vSphere. Ora puoi gestire i datastore sull'host.

.Argomenti correlati
* link:../manage/mount-a-vvols-datastore.html["Montare un datastore vVols"]sui nuovi host.
* link:../manage/mount-datastores-on-host.html["Montare il datastore NFS e VMFS"]sui nuovi host.
